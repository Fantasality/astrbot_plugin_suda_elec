# 苏大宿舍电费监控 · astrbot_plugin_suda_elec

免统一身份认证监控**苏州大学**宿舍剩余电费：多宿舍挂载、余额曲线、低额预警、Bot 查询工具。

> 数据来源：苏州大学水电缴费平台 <https://ny.hq.suda.edu.cn/prepaid/>

## 为什么不需要登录？

平台的「校区 → 楼栋 → 房间」浏览接口与「绑定设备」接口只校验公共设备令牌（前端硬编码），
不校验用户身份。插件因此使用一个**自生成的虚拟账号**（形如 `astrbot-elec-xxxxxxxx`）完成
房间绑定与余额查询——无需 Cookie、无需密码、无需微信授权，且**可以添加任意校区任意宿舍**。

## 快速开始

1. 安装并启用插件；
2. 打开 AstrBot WebUI 左侧的「苏大电费监控」插件页面；
3. 「添加宿舍」：选择 校区 → 楼栋 → 房间 → 添加（可添加任意多个）；
4. 在聊天里发 `/elec alert here` 把当前会话设为预警接收目标（或在页面设置里填写）；
5. 完成：默认每 30 分钟自动记录一次余额，低于阈值自动预警。

## Bot 命令

| 命令 | 说明 |
| --- | --- |
| `/elec` 或 `/elec help` | 帮助 |
| `/elec check` | 立即轮询一次并回报 |
| `/elec list` | 查看监控列表、余额与阈值 |
| `/elec threshold <关键词> <元>` | 设置单宿舍预警阈值 |
| `/elec alert here` | 把当前会话加入预警接收列表 |
| `/elec remove <关键词>` | 移除监控 |

## LLM 工具（对话直接问）

- `elec_query`：查询宿舍余额、24h 变化、区间统计、阈值状态；
- `elec_watchlist`：查询插件运行状态（挂载数、间隔、上次轮询结果）。

## WebUI 插件页

- 宿舍卡片：余额大数字滚动动画、较上次涨跌徽标、迷你走势图、行内阈值编辑、移除；
- 余额曲线：Canvas 手绘（渐变填充、入场动画、悬停十字线与数值提示），24h / 7d / 30d / 全部；
- 添加宿舍：校区 → 楼栋 → 房间三级选择器；
- 设置：轮询间隔、全局阈值、预警开关、预警会话、消息模板、冷却时间。

## 数据文件

保存在 `data/plugin_data/astrbot_plugin_suda_elec/`：

- `state.json`：虚拟账号、房间清单、预警状态；
- `records.json`：各宿舍余额历史（时间序列）。

## 免责声明

本项目仅查询宿舍电费余额，不涉及充值支付等写操作（充值仍请前往官方平台）。
请控制查询频率（默认 30 分钟，最低 5 分钟），尊重学校公共接口。
